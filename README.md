# E-Commerce Data Engineering & Analytics Pipeline

An end-to-end data engineering and analytics project using Python, Pandas, NumPy, MySQL, and SQL.

## Project Overview

This project builds an ETL pipeline for an e-commerce dataset. The pipeline extracts raw data, cleans and transforms it using Python, validates data quality, and loads the processed data into a MySQL data warehouse.

SQL queries are then used to analyze sales trends, customer behavior, product performance, revenue, and other business metrics.
